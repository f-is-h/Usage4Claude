# Icon Placeholder Notice

The current app icon (all sizes in `Assets.xcassets/AppIcon.appiconset/`,
`AppIconReverse.imageset/`, and the `.icns` / `icon@2x.png` files in this
directory) is a **temporary recolor** of the upstream
[f-is-h/Usage4Claude](https://github.com/f-is-h/Usage4Claude) icon.

A 160-degree hue rotation was applied to the original artwork to make the
UsagePaceCC fork visually distinct from upstream while a bespoke icon is
being designed.
