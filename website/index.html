Core Features

Professional monitoring tool designed for Claude and Codex users

📊

Real-time Monitoring

Track the 5-hour, 7-day and Extra Usage limits, plus weekly usage for every model the API returns (Opus, Sonnet, Fable and beyond). Colour-coded rings with distinctive shapes stay readable at a glance.

🧩

Codex Support

Monitor Codex 5-hour, 7-day and credit usage on its own or side by side with Claude. Sign in through the system browser, and nothing changes for Claude-only users until a Codex account is added.

🌐

Cross-Platform Support

Unified monitoring for all Claude products: Web, Claude Code, Desktop App, Mobile App and Cowork - they share one quota, viewed in one place.

👥

Multi-Account Management

Add multiple Claude and Codex accounts, name them with aliases, and switch from the menu bar. One sign-in picks up every organisation on the account automatically.

🔔

Usage Notifications

Native macOS alerts warn you when usage crosses 90% and tell you the moment a quota resets. Each limit type is tracked on its own, and the whole thing can be switched off.

🔄

Smart Refresh & Auto Update

4-level adaptive refresh runs every minute while you work and eases to 10 minutes when idle, or pick a fixed interval. The app also updates itself in place.

🎨

Personalization

Smart Mode detects the limits you actually have, or choose them yourself. 3 menu bar themes, 3 icon sizes, and system / light / dark appearance modes.

🌍

Multi-Language Support

The app speaks 7 languages: English, Japanese, Korean, Simplified Chinese, Traditional Chinese, French and German. It follows your system language, or you can pick one.

🔒

Security & Privacy

Everything stays on your Mac. Claude and Codex credentials live in the Keychain, the app runs sandboxed, and the source is fully open for anyone to audit.
