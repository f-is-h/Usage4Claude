Claude와 Codex 사용량
실시간 모니터링

모든 Claude 플랫폼을 아우르는 우아한 macOS 메뉴 바 앱, Codex 모니터링도 선택 가능

  • • 다중 제한 표시 - 5시간, 7일, 추가 사용량, 모델별 주간 사용량
  • • Claude + Codex - 하나만 또는 두 개를 나란히 모니터링
  • • 프라이버시 우선 - 로컬 저장, 오픈 소스, Keychain 암호화
최신 버전 다운로드 ⭐ Star on GitHub

주요 기능

Claude와 Codex 사용자를 위한 전문 모니터링 도구

📊

실시간 모니터링

5시간, 7일, 추가 사용량 제한은 물론 API가 반환하는 모든 모델의 주간 사용량(Opus, Sonnet, Fable 등)을 표시합니다. 모양이 다른 색상 링으로 한눈에 구별됩니다.

🧩

Codex 지원

Codex의 5시간, 7일, 크레딧 사용량을 단독으로 또는 Claude와 나란히 모니터링. 시스템 브라우저로 로그인하며, Codex 계정을 추가하기 전까지 Claude만 쓰는 경험은 그대로입니다.

🌐

크로스 플랫폼 지원

모든 Claude 제품 통합 모니터링: 웹 버전, Claude Code, 데스크톱 앱, 모바일 앱, Cowork —— 같은 사용량을 한 곳에서 확인.

👥

다중 계정 관리

여러 Claude와 Codex 계정을 추가하고 별칭을 지정해 메뉴 바에서 전환하세요. 한 번 로그인하면 해당 계정의 모든 조직을 자동으로 가져옵니다.

🔔

사용량 알림

macOS 네이티브 알림으로 사용량이 90%를 넘으면 경고하고, 사용량이 초기화되는 순간을 알려줍니다. 제한 유형별로 개별 추적하며 전체를 끌 수도 있습니다.

🔄

스마트 갱신 및 자동 업데이트

4단계 적응형 갱신: 작업 중에는 1분 간격, 유휴 시에는 10분까지 점진적으로 완화되며 고정 간격도 선택 가능. 앱 자체도 제자리에서 자동 업데이트됩니다.

🎨

개인화

스마트 모드가 실제 보유한 제한을 자동 감지하며 직접 선택할 수도 있습니다. 3가지 메뉴 바 테마, 3단계 아이콘 크기, 시스템/라이트/다크 외관 모드.

🌍

다국어 지원

앱은 7개 언어를 지원합니다: 영어, 일본어, 한국어, 간체 중국어, 번체 중국어, 프랑스어, 독일어. 시스템 언어를 자동으로 따르거나 직접 선택할 수 있습니다.

🔒

보안 및 프라이버시

모든 데이터는 Mac 안에만 남습니다. Claude와 Codex 자격 증명은 Keychain에 저장되고, 앱은 샌드박스에서 실행되며, 소스는 누구나 감사할 수 있도록 완전히 공개되어 있습니다.
