核心功能

为 Claude 与 Codex 用户设计的专业监控工具

📊

实时监控

监控 5 小时、7 天和额外用量限制，并按接口返回展示各模型的周用量（Opus、Sonnet、Fable 等）。智能色彩进度环搭配独特形状，一眼看清。

🧩

Codex 支持

监控 Codex 的 5 小时、7 天和积分用量，可单独使用，也可与 Claude 并排显示。通过系统浏览器登录；未添加 Codex 账号前，只用 Claude 的体验完全不变。

🌐

跨平台支持

统一监控所有 Claude 产品：Web 网页版、Claude Code、桌面应用、移动应用与 Cowork —— 共用一份配额，一处查看。

👥

多账号管理

可添加多个 Claude 与 Codex 账号，设置别名，从菜单栏快速切换。一次登录会自动识别该账号下的所有组织。

🔔

用量通知

原生 macOS 通知：用量超过 90% 时提醒，配额重置时告知。每种限制类型独立跟踪，也可整体关闭。

🔄

智能刷新与自动更新

4 级自适应刷新：使用时每分钟刷新，闲置时逐步降至 10 分钟，也可固定间隔。应用还会自动检查并原地完成更新。

🎨

个性化定制

智能模式自动识别你实际拥有的限制，也可自行选择。3 种菜单栏主题、3 档图标尺寸，以及跟随系统 / 浅色 / 深色外观。

🌍

多语言支持

应用界面支持 7 种语言：英语、日语、韩语、简体中文、繁体中文、法语和德语。自动跟随系统语言，也可手动切换。

🔒

安全隐私

所有数据只留在你的 Mac 上。Claude 与 Codex 凭据保存在 Keychain 中，应用运行于沙盒内，代码完全开源可审计。
