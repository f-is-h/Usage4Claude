Privacy Policy

Core Principle

We do not collect any user data.

Usage4Claude is a 100% local application. All data is stored only on your Mac.

Data Storage

Local Storage

  • Usage quota data: Cached locally after fetching from the Claude and Codex APIs
  • App settings: Stored in local user preferences
  • No data uploaded to any external servers

Keychain Encryption

  • Claude credentials (Organization ID, Session Key or OAuth token) and Codex authentication tokens: Encrypted in macOS Keychain
  • Encryption: AES-256 + Hardware protection (T2/Secure Enclave)
  • Access Control: Only this app can access, other apps cannot read

Network Requests

These are the only requests the app makes. Your usage data is never sent anywhere.

Claude API (claude.ai, api.anthropic.com, console.anthropic.com)

  • Purpose: Fetch your usage quota and refresh the sign-in token
  • Frequency: Based on settings (1-10 min intervals)
  • Content: Only your own authentication info, no other data

Codex API (chatgpt.com, auth.openai.com)

  • Only sent once you add a Codex account - nothing is requested otherwise
  • Purpose: Fetch Codex usage and renew the session
  • Content: Only your own authentication info, no other data

Update Check (raw.githubusercontent.com)

  • Purpose: Read the public release feed to detect new versions
  • Content: Carries nothing about you or your account

Codex Reset Announcement, Beta (codex-reset.com)

  • The only third-party service the app contacts. codex-reset.com is an independent community project, not an official OpenAI service
  • Purpose: Show a badge when a still-pending global Codex reset has been publicly announced
  • Content: No account info and no usage data is sent. Runs only when a Codex account exists, and can be switched off in Settings

No Tracking, No Analytics

  • ❌ No Google Analytics
  • ❌ No other analytics tools
  • ❌ No ad tracking
  • ❌ No third-party analytics or ad SDKs
  • ✅ Completely zero tracking

Open Source Transparency

  • Source Code: GitHub Repository
  • License: MIT License
  • Audit: Anyone can review and audit the code
  • No Obfuscation: Fully transparent, no hidden features
  • Third-party components: only the Sparkle update framework, used to check for and install updates - no analytics or tracking library is bundled

Data Security

  • ✅ App Sandbox Enabled - Limits system access
  • ✅ Keychain Encryption - Hardware-level protection for sensitive info
  • ✅ Minimal Permissions - Only requests necessary permissions (Network + Keychain)
  • ✅ No File Access - Does not access your files, contacts, etc.

Your Rights

  • Delete app and data anytime
  • View/delete credentials via "Keychain Access" app
  • No data residue concerns - all data stored locally only

Policy Changes

If this privacy policy changes, updates will be posted here and users will be notified in the app.
