主な機能

Claude と Codex のユーザーのために設計されたプロフェッショナル監視ツール

📊

リアルタイム監視

5時間・7日間・追加使用量の制限に加え、API が返すすべてのモデルの週間使用量（Opus、Sonnet、Fable など）を表示。形状の異なるカラーコード付きリングで一目で判別できます。

🧩

Codex 対応

Codex の5時間・7日間・クレジット使用量を、単独でも Claude と並べても監視。ログインはシステムブラウザ経由。Codex アカウントを追加するまで、Claude だけの使い勝手は一切変わりません。

🌐

クロスプラットフォーム対応

すべての Claude 製品を統一監視：Web版、Claude Code、デスクトップアプリ、モバイルアプリ、Cowork —— 同じ使用量枠を一箇所で確認。

👥

複数アカウント管理

Claude と Codex のアカウントを複数追加し、エイリアスを付けてメニューバーから切り替え。1回のログインでそのアカウントの全組織を自動的に取得します。

🔔

使用量通知

macOS ネイティブ通知で、使用量が90%を超えたときに警告し、使用量枠がリセットされた瞬間をお知らせ。制限タイプごとに個別に追跡し、まとめてオフにもできます。

🔄

スマート更新と自動アップデート

4段階の適応型更新：作業中は1分間隔、アイドル時は10分間隔まで緩やかに移行。固定間隔も選択可能。アプリ自体もその場で自動更新されます。

🎨

パーソナライゼーション

スマートモードが実際に利用可能な制限を自動検出、手動選択も可能。3つのメニューバーテーマ、3段階のアイコンサイズ、システム/ライト/ダークの外観モード。

🌍

多言語対応

アプリは7言語に対応：英語、日本語、韓国語、簡体字中国語、繁体字中国語、フランス語、ドイツ語。システム言語に自動追従、手動切替も可能。

🔒

セキュリティとプライバシー

すべてのデータは Mac 内にとどまります。Claude と Codex の認証情報は Keychain に保存され、アプリはサンドボックス内で動作。ソースコードは完全公開で誰でも監査できます。
